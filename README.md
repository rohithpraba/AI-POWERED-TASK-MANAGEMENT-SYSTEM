# Software Bug Priority Classification

> **Status:** Earlier multiclass NLP experiment under methodology and result re-evaluation. This repository is not used as current flagship evidence.

The public notebook explores five-class software bug-priority classification from issue summary and description text. It includes TF-IDF features, class-imbalance experiments, Logistic Regression, Random Forest, XGBoost, a voting ensemble, SHAP-related analysis, and a prototype inference interface.

## Why the repository is being re-evaluated

The current public notebook does not establish every dataset count and result previously associated with this project. The next release will use one reproducible source definition and will report only metrics generated by that version.

The rebuilt evaluation must also:

- split data before fitting TF-IDF;
- compare against a majority-class baseline;
- report macro-F1 and per-class recall alongside weighted metrics;
- avoid complete-case deletion based on optional fields;
- keep sparse text representations where possible;
- package preprocessing and classification together for inference;
- attach explanation methods to the model actually being interpreted.

## Current use

The notebook remains public to preserve the learning history. It should be read as an experiment, not as a validated production task-management system or a final benchmark.

## Metrics intentionally omitted

This README does not publish the earlier unresolved dataset-count, class-balancing, or best-model claims. They may return only if the exact original experiment is recovered and independently audited, or after a new reproducible build replaces them.
